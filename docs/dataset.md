# Dataset — The Movies Dataset (Kaggle)

O dataset The Movies Dataset contém metadados sobre filmes, elenco, equipes e avaliações de usuários.


## Estrutura dos arquivos

| Arquivo | Descrição | Volume |
|----------|------------|--------|
| `movies_metadata.csv` | Dados principais dos filmes | 34.45 MB |
| `ratings.csv` | Avaliações de usuários | 709.55 MB |
| `credits.csv` | Elenco e diretores | 189.2 MB |
| `keywords.csv` | Palavras-chave associadas | 6.23 MB |
| `links.csv` |  IDs do TMDB e do IMDB de todos os filmes | 989.11 KB |
| `links_small.csv` | IDs do TMDB e do IMDB de um pequeno subconjunto de 9.000 filmes | 183.37 KB |
| `ratings_small.csv` | O subconjunto de 100.000 avaliações de 700 usuários sobre 9.000 filmes. | 2.44 MB |

title: Inception release_date: 2010-07-16 genres: Action, Science Fiction vote_average: 8.3
