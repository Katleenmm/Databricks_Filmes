# Projeto Databricks Filmes

Este projeto demonstra a construção de um **Data Lakehouse** baseado no **Databricks Community Edition**, aplicando a arquitetura **Medalhão (Landing, Bronze, Silver e Gold)** e tecnologias como **Apache Spark**, **Delta Lake** e **Apache Iceberg**.


## Objetivos do projeto

- Entender a arquitetura **Medalhão (Medallion Architecture)**.  
- Criar **pipelines de transformação** com Apache Spark.  
- Implementar **SCD Type 2** para histórico de dados.  
- Realizar análises e visualizações a partir da camada **Gold**.

---

## Tecnologias utilizadas

| Tecnologia | Finalidade |
|-------------|-------------|
| Databricks | Execução de notebooks e Spark clusters |
| Apache Spark | Processamento distribuído |
| Delta Lake | Versionamento e controle ACID |
| Apache Iceberg | Gerenciamento de tabelas no Lakehouse |
| Python / PySpark | Linguagem de implementação |
| Kaggle Dataset | Fonte de dados original |
