# Pipeline de Dados — Landing, Bronze, Silver e Gold

!!! info "Visão geral"
    O **pipeline de dados** define o fluxo completo de ingestão, disponibilização e transformação dos dados no ambiente Databricks.  
    Ele é estruturado em quatro camadas principais — **Landing → Bronze → Silver → Gold** — garantindo rastreabilidade, qualidade e governança ao longo de todo o processo. Em projetos no Databricks, o pipeline segue o padrão ELT, é dividido nas camadas Medalhão, e é automatizado via Jobs e Workflows.
